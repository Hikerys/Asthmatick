# Нативная Android-версия

Интерфейс работает на Android Views / Material Components 3 (Java 17).
В сборке нет React, Capacitor, WebView, JavaScript или HTML-экранов.
Материальные карточки, кнопки, нижняя навигация и нижние окна используют
нативные elevation, ripple, фокус, клавиатуру и accessibility.

## Карта кода

Все Java-файлы находятся в `android/app/src/main/java/app/asthma/tick/`:

- `MainActivity.java`: четыре раздела, формы, навигация, диалоги, выбор файлов.
- `PickerSheets.java`: прежние окна выбора времени и даты, включая стрелки и быстрые шаблоны.
- `Palette.java`: исходные светлая и тёмная палитры; системные Monet-роли Android 12+.
- `NativeStore.java`: SQLite и транзакционный импорт; экспорт через системный выбор файла.
- `Records.java`: совместимая JSON-модель, валидация и доступ к записям.
- `ScheduleRules.java`: окно отметки ±60 минут, пропуски и завершённые приёмы.
- `ReminderReceiver.java`: AlarmManager, каналы звука и восстановление после перезагрузки.

Ресурсы: `res/drawable/ic_*.xml` — векторные иконки из исходных контуров;
`res/raw` — прежние звуки, тексты RU/EN и правовые документы;
`res/mipmap-*` — прежние иконки приложения.

## Совместимость данных

Сохраняются `applicationId=app.asthma.tick`, файл `asthmatick.db`, версия схемы 1,
таблицы `schedule_events`, `attacks`, `notes`, `settings`, `metadata` и JSON-поля.
Обновление с версии 1.3.2 читает базу непосредственно. Сохраняются идентификаторы,
время создания, дни недели, `completedDates`, `completionTimes` и настройки.

Импорт принимает SQLite-копии Asthmatick до 32 MiB. Проверка целостности и модели
происходит до транзакции записи. Отмена выбора или невалидный файл не заменяют
данные. Экспорт содержит самостоятельную SQLite-базу.

Версии до перехода на SQLite хранили записи в localStorage. Перед прямым
обновлением с такой версии нужно открыть 1.3.2 для миграции либо иметь SQLite-копию;
нативная версия не запускает WebView для чтения старого localStorage.

## Дизайн

Исходные параметры перенесены в dp/sp: верхняя панель 64, нижняя 76,
карточки с радиусом 16, контейнеры иконок 44/12, FAB 56/16, нижние окна 28.
Светлая палитра: фон `#e9f6f6 → #f4f9fb`, заголовок `#cfe8e2 → #d9f0ef`,
акцент `#1a9b8c`, текст `#0f2b46`, карточки `#ffffff`.
Тёмная: фон `#0e1a22 → #101d27`, карточки `#172a35`, акцент `#33c2b0`.
Сохранены волна и лёгкие, круглые даты календаря, цветовая шкала тяжести,
группы настроек и три вкладки нижней навигации.

Окна выбора даты и времени собраны из BottomSheetDialog, MaterialButton, Chip
и Android Views с исходными стрелками, календарной сеткой и быстрыми шаблонами.

## Сборка и проверка

Нужны JDK 17+, Android SDK 36 и доступ к Maven при первой сборке.
Путь SDK задаётся в `android/local.properties` или `ANDROID_HOME`.

```sh
./scripts/build-apk.sh debug
./scripts/build-apk.sh release
./android/gradlew -p android testDebugUnitTest lintDebug
```

Release APK находится в `releases/Asthmatick.apk` и копируется в корень проекта.
Release использует существующую конфигурацию подписи.
Debug не предназначен для установки поверх release с другой подписью.

Тесты проверяют границы окна приёма, чтение базы прежней схемы, отказ от
невалидных данных, экспорт/импорт, нативные экраны и создание заметки через форму.
Robolectric-превью — `android/app/build/native-previews/`; они не заменяют проверку
на реальном телефоне (системные панели, клавиатура, жесты, разрешения и доставка
напоминаний в Doze).

Напоминания ставятся на ближайший приём каждого расписания и повторно планируются
после доставки, перезагрузки, обновления и смены часового пояса. Без доступа к
точным будильникам используется неточное системное напоминание; статус виден в
настройках. Разрешение уведомлений запрашивается при включении напоминаний.
